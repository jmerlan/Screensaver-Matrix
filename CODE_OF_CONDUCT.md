# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback
gracefully, and don't harass anyone. This applies to issues, pull requests, discussions and any other
project space.

## Reporting

If you experience or witness unacceptable behavior, please contact the maintainers privately through
GitHub (for example, via the email address on a maintainer's GitHub profile). All reports will be
reviewed promptly and kept confidential.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that
don't follow this Code of Conduct, and may temporarily or permanently ban contributors for
inappropriate behavior, as described in the Contributor Covenant's enforcement guidelines.
